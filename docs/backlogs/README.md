# Backlogs

This directory contains versioned implementation backlogs that are still active or still being developed.

Current active backlog set: [`v1/`](./v1/).

Rules:

- `vN/` groups backlog briefs for that development baseline.
- Backlog documents describe scoped implementation work and do not override canonical/domain authority.
- Canonical `OPEN` or `FUTURE` items do not automatically become active backlog work unless explicitly scoped.
- Delivered items may remain inside an active `vN/` while that backlog version is still being developed; archiving or closing a backlog version is a separate explicit decision.
