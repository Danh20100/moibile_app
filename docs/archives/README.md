# Documentation Archives

`docs/archives/` stores repository documentation retained for provenance but no longer part of a current official authority surface.

Use this area for pre-versioned, superseded-before-release, or obsolete artifacts. Official historical database releases remain under `docs/database/vN/` and are **not** moved here when a newer release is created.

Current database pre-versioning material lives under `database/pre-versioned/`.

Delivered historical backlog briefs live under `backlogs/`; they are retained for provenance and must not be treated as current implementation work.
